# 文档索引

本目录按“官方产品规则、开发入口、功能开发规格、专题资料、学习笔记”分层。文档的权威性由所属目录决定，不以文件创建时间判断。

## 官方产品规则

- [`product/`](./product/README.md)：产品定位、需求、交互、产品决策和稳定技术边界的唯一官方入口。

## 开发入口

- [开发指南](./DEVELOPMENT.md)：环境准备、启动、检查、测试和常见问题。
- [`development/`](./development/README.md)：当前功能的开发规格与模板。

## 专题资料

- [`voice/`](./voice/)：语音能力的规格、任务和实现交接资料。

## 学习笔记

- [`note/`](./note/)：代码阅读、研究和问答笔记，不构成产品或实现契约。

## 文档边界

- 已确认且长期稳定的产品规则写入 `product/`。
- 开发环境和项目级工程约定写入 `DEVELOPMENT.md`。
- 可以直接指导某项功能实施的临时开发规格写入 `development/`。
- 专题探索和阶段材料放入对应专题目录。
- 个人理解、代码阅读和研究内容放入 `note/`。
- 功能完成后，开发规格中的稳定结论合并进 `product/TECHNICAL.md` 或 `product/INTERACTION.md`；开发规格随后删除，由 Git 历史保留。
