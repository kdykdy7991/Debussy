# 资源与 Skill 加载

`DefaultResourceLoader` 负责加载：

- `AGENTS.md` 等上下文文件。
- skills。
- prompt templates。
- themes。
- extensions。
- `SYSTEM.md` 和 `APPEND_SYSTEM.md`。

主要实现：

- `../packages/coding-agent/src/core/resource-loader.ts`
- `../packages/coding-agent/src/core/package-manager.ts`
- `../packages/coding-agent/src/core/skills.ts`

## Skill 默认发现位置

Pi 会从以下来源发现 skills：

```text
~/.pi/agent/skills/
~/.agents/skills/
当前项目/.pi/skills/
当前目录及父目录的 .agents/skills/
settings.json 中配置的额外路径
命令行 --skill 指定的路径
extensions 动态提供的 skill
```

每个磁盘 skill 通常是一个包含 `SKILL.md` 的目录。加载器会递归搜索 `SKILL.md`，解析其 frontmatter 和正文。

当前机器确认存在：

```text
/home/hello/.agents/skills/dashi-ppt/SKILL.md
/home/hello/.agents/skills/find-skills/SKILL.md
```

因此即使当前仓库没有安装 skill，用户级目录中的 skill 仍会显示。扩展还可以在运行时动态提供 skill，这类 skill 不一定对应当前仓库内的文件。

## 页面如何显示资源

`InteractiveMode.showLoadedResources()` 调用：

```ts
this.session.resourceLoader.getSkills();
this.session.resourceLoader.getPrompts();
this.session.resourceLoader.getExtensions();
```

然后生成 `[Context]`、`[Skills]`、`[Prompts]` 和 `[Extensions]` 区域。Ctrl+O 可以展开资源详情和来源。

## 禁用 Skill

启动时禁止发现和加载 skills：

```bash
./node_modules/.bin/tsx \
  --tsconfig ./tsconfig.json \
  ./packages/coding-agent/src/cli.ts \
  --no-skills
```

`--no-skills` 只关闭 skills，不会关闭 prompts、extensions 或上下文文件。
