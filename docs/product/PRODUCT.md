# 产品说明

## 产品定位

Debussy 是面向企业 AI Agent 建设与交付的工作台。管理员在同一产品内完成 Agent 配置、调试、发布、用量核对和线上会话排查，并将已发布的 Agent 以独立 Embed 对话接入企业网站。

它不是面向普通用户的泛用聊天产品，也不是完整 BI、CRM 或模型训练平台。

## 核心用户

- 企业管理员：配置、调试和发布 Agent。
- 企业网站接入开发者：取得发布应用的接入配置并完成集成。
- 运营与支持人员：在权限和脱敏边界内排查线上用户会话。

## 核心价值

- 让 Agent 从配置、验证到发布形成可理解、可回滚的闭环。
- 将管理员调试与企业终端用户会话严格隔离。
- 让发布版本、用量和线上问题能够追溯到明确的 Agent 与应用。
- 以真实系统状态为准，不用演示数据伪装生产结果。

## 长期产品边界

- 一个 Agent 可以被多个发布应用引用。
- 发布应用显式绑定 Agent Revision，并拥有独立访问方式与发布状态。
- 管理员 Chat 用于调试；Embed Chat 服务企业终端用户。
- 线上会话绑定发布应用、版本和主体，不与管理员调试会话混用。
- 发布必须可验证、可回滚，不能隐式修改其他应用。
