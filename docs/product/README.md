# 官方产品文档

本目录是 Debussy 产品层面的唯一官方真相源，只记录已经确认、跨开发周期稳定的内容。

## 官方文档

1. [PRODUCT.md](./PRODUCT.md)：产品定位、用户、价值与长期边界。
2. [PRD.md](./PRD.md)：当前确认的产品能力、核心流程与验收结果。
3. [INTERACTION.md](./INTERACTION.md)：跨页面稳定的状态、反馈与交互规则。
4. [DECISIONS.md](./DECISIONS.md)：已经接受的产品决策及理由。
5. [TECHNICAL.md](./TECHNICAL.md)：产品依赖的稳定技术边界与系统关系。
6. [ROADMAP.md](./ROADMAP.md)：当前阶段、交付顺序、范围与阶段完成条件。
7. [METRICS.md](./METRICS.md)：产品漏斗、体验、系统健康指标与口径要求。
8. [QUALITY.md](./QUALITY.md)：功能完成定义、测试分层、发布门禁与验收证据。
9. [RELEASE-SOP.md](./RELEASE-SOP.md)：版本候选、发布、观察、回滚与发布记录。
10. [INCIDENT-SOP.md](./INCIDENT-SOP.md)：故障分级、止损、恢复、沟通与复盘流程。

除以上文件外，`docs/` 中的计划、任务单、交接、报告、研究和历史规格都属于工作资料或实现证据，不自动代表当前产品规则。

## 写入门槛

只有同时满足以下条件的内容才写入本目录：

- 已经由产品负责人确认；
- 在多个开发任务或版本之间仍然成立；
- 会影响产品边界、用户流程、统一交互或系统契约；
- 能用明确陈述表达，不依赖“可能”“计划”“暂定”等措辞。

开发步骤、排期、临时方案、任务进度、调试记录和待讨论想法不得写入本目录。

## 修改规则

- 日常实现不得顺手改变官方产品规则。
- 产品规则变化必须先明确决策，再同步修改受影响的官方文档。
- 同一条规则只在一份文档中定义；其他文件通过链接引用。
- 不确定内容保留在 issue、任务单或讨论记录中，确认后再进入这里。
- 路线图、指标和 SOP 中未获确认的组织、阈值或生产配置必须明确标记为“待确认”，不得作为已生效承诺。
