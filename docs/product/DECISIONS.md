# 产品决策

本文件只记录已经接受、会长期影响产品的决策。

## D-001 管理员调试与线上用户会话分离

管理员 Chat 是调试环境；Session 日志和 Embed Chat 面向已发布应用的企业用户。两类会话在术语、权限和用量归属上保持隔离。

## D-002 发布应用显式绑定 Revision

线上应用使用不可变 Agent Revision。修改 Agent 配置不会绕过发布流程直接影响线上应用。

## D-003 真实状态优先

界面不使用模拟数据伪装真实连接或运行结果。离线、错误和未配置状态必须明确展示。

## D-004 管理员凭据不由前端界面管理

开发环境由代理注入管理员凭据，生产环境由网关注入。凭据不进入 URL、浏览器存储或可见错误信息。
