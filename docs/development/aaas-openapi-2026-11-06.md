# Agent 任务 API 在线文档

状态：可开发

创建日期：2026-11-06

## 目标与范围

为业务接入方提供可访问的 OpenAPI 描述和交互文档，只列出任务下发、查询、取消三个明确授权的接口。保持业务接口、鉴权和数据不变，不自动暴露管理接口。页面同源请求业务 API，不预置任何凭据。

## 方案调研与选型

现有服务使用 Node HTTP 和 Zod 3，已有 Markdown 接入说明，没有 OpenAPI 或文档 UI。Fastify/Nest 的自动生成依赖其路由框架，迁移框架成本与风险不合适。Swagger UI 官方提供服务端静态资源包 swagger-ui-dist（Apache-2.0）；其本地资源可以离线部署，无需 CDN。已检查 npm 元数据和包内容，5.34.1 包含静态资源及 @scarf/scarf 依赖，安装时禁用生命周期脚本。Zod 3 的 zod-to-json-schema 已停止维护，不作为新直接依赖；Zod 4 原生转换需要整体升级，不在本次范围。选择显式编写有限 OpenAPI 契约，用实际 HTTP 行为测试守护关键请求和响应，后续变更必须同步维护；测试无法证明所有语义一致。若文档维护成本上升或契约测试反复失效，重新评估共享 schema 方案。

## 实施和验收

- 后端提供独立页面、静态资源与 OpenAPI JSON；只列三个接口，保留现有鉴权。无真实 Token，关闭外部校验器和远程资源。
- 定义请求、响应、错误、鉴权、幂等和取消语义；文档与实际 API 测试覆盖关键边界及白名单。
- 本地前端开发代理应提供同源访问；对局域网的暴露遵循既有访问限制。
- 更新接入说明及维护流程，接口改变时运行专项测试并检查文档。部署配置须按需映射文档路径；不擅自重启现有服务。
