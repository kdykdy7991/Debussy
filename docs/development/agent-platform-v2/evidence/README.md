# Agent 平台 V2 验收证据

本目录保存 M0～M4 的可复核验收记录，不保存密钥、Token、完整用户内容、数据库备份或大型二进制产物。

## 文件规则

- 每个里程碑使用一个 Markdown 文件：`m0.md`、`m1.md`、`m2.md`、`m3.md`、`m4.md`。
- 截图、完整日志和性能产物保存在仓库外；文档只记录安全路径、摘要或受控系统链接。
- 每次重新验收追加新的候选记录，不覆盖失败证据。
- 结论只能是：`通过`、`有条件通过`、`不通过`。

## 记录模板

```text
里程碑：
候选提交/构建：

回退演练：
已知限制和风险：
结论：通过 / 有条件通过 / 不通过
遗留项、负责人、截止里程碑：
产品负责人决定：进入下一阶段 / 退回修复
```
