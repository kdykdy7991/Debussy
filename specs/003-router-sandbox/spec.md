# Router 受限本地 Bash

管理员可在 Router Key 直接能力中保存 `local_tools: ["bash"]`。未设置或为空时无本地权限。每次受理冻结该授权并纳入既有快照摘要。创建与追加输入的请求字段保持原样。

授权 Operation 只能通过 Linux bwrap 使用 Pi Bash。工作区按租户与 Task 分配，在同一 Task 后续 Operation 中复用。固定 Python、Node 和预装依赖只读共享。Sandbox 不挂载宿主根、平台凭据或其他 Task 工作区，使用最小环境并隔离网络。

通过实际 Pi 模型请求检查可见工具，验证直接提交的未授权调用被拒绝。执行侧验收覆盖读写、共享运行时、网络、启动失败、超时与取消。独立记录本地真模型通过公开 Router 接口的 Python、Node 结果。

首版使用单一 Linux Provider。发布 Chat、后台 Coding Chat 和既有 MCP 权限沿用自身执行入口。

## 管理端运行环境与执行统计

- 管理员可在「Sandbox 环境」即时检查配置的 Bubblewrap、执行策略、工作区、实际运行时及 Python 依赖，可搜索依赖清单。探测使用同一隔离启动方式和临时工作区，失败时显示当前错误。
- 执行统计按单次 Bash 启动尝试记录结果，区分成功、命令失败、启动失败、超时和取消。按 24 小时、7 天、30 天聚合，最近记录关联 Router Operation。凭据、命令正文及工具输出沿用既有权限保护，统计接口仅返回结构化执行结果。
- 运行环境 Tab 展示概览、运行时卡片、可搜索的依赖表和默认折叠的路径详情。执行统计 Tab 展示四项指标、真实执行次数趋势、结果分布和最近记录。分布合计超时与取消，单条记录保留各自状态。
- 管理员在 Router Operation 执行轨迹可查看每次 Bash 调用的命令和对应输出，分别脱敏并限制展示长度。模型用量查询和对外事件仍沿用原有口径。
- 并发验收通过两个独立 Task，核对实际 Bash 执行时段重叠、命名空间与工作区隔离、共享只读运行根，以及取消后另一任务仍能完成。调度沿用 Router 的 Task 占用规则。
