# CLI 运行与调试

## 通过源码启动

`pi-test.sh` 最终通过 `tsx` 执行 TypeScript 入口：

```bash
./node_modules/.bin/tsx \
  --tsconfig ./tsconfig.json \
  ./packages/coding-agent/src/cli.ts \
  --offline \
  --provider oneapi \
  --model Qwen3.6-35B-A3B-NVFP4
```

单次非交互请求：

```bash
./node_modules/.bin/tsx \
  --tsconfig ./tsconfig.json \
  ./packages/coding-agent/src/cli.ts \
  --offline \
  --provider oneapi \
  --model Qwen3.6-35B-A3B-NVFP4 \
  -p "Say exactly: ok"
```

`--offline` 禁止在线刷新模型目录，不会禁止向 OneAPI 发送推理请求。

## VS Code 调试

调试配置位于 `../.vscode/launch.json`。在仓库根目录打开 VS Code，进入“运行和调试”，选择 `Debug pi CLI (OneAPI)` 后按 F5。

VS Code 调试和命令行运行的入口相同，区别是调试模式支持 TypeScript 断点、单步执行、变量查看和异常暂停。交互模式必须使用 integrated terminal。

## 相关入口

- `../packages/coding-agent/src/cli.ts`：Node/tsx 入口。
- `../packages/coding-agent/src/main.ts`：启动流程编排。
- `../packages/coding-agent/src/cli/args.ts`：命令行参数解析。
