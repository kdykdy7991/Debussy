# CLI 交互模式启动调用链

从执行 `cli.ts` 到可以输入第一句话，主调用链如下：

```text
cli.ts
  → main()
  → 解析参数并确定运行模式
  → 加载配置与会话
  → 加载模型和项目资源
  → 创建 AgentSession
  → 创建 InteractiveMode
  → 初始化终端 TUI
  → 绑定扩展和 Agent 事件
  → 渲染启动页面
  → 等待用户输入
```

## 1. 进程入口

`../packages/coding-agent/src/cli.ts` 设置进程名称和环境变量，初始化 HTTP dispatcher，然后调用：

```ts
main(process.argv.slice(2));
```

它不负责界面绘制。

## 2. 参数解析和模式选择

`../packages/coding-agent/src/main.ts` 中的 `main()` 负责启动编排：

- 处理 `--offline`、`--provider`、`--model`、`--print` 等参数。
- 根据 stdin/stdout 是否为 TTY 确定 `interactive`、`print`、`json` 或 `rpc` 模式。
- 执行配置迁移和首次启动设置。

没有使用 `-p` 且运行在真实终端时，会进入 `interactive` 模式。

## 3. 配置和会话

`SettingsManager` 合并用户级与项目级配置。默认用户配置目录为 `~/.pi/agent`。

`SessionManager` 负责：

- 创建或恢复会话。
- 读取历史消息。
- 确定会话工作目录。
- 持久化后续消息和会话元数据。

`ProjectTrustStore` 检查项目资源是否可信，因为项目 extensions 和 skills 可能执行代码或改变模型上下文。

## 4. 创建基础服务

`../packages/coding-agent/src/core/agent-session-services.ts` 中的 `createAgentSessionServices()` 创建：

- `ModelRuntime`：读取认证和模型配置、注册 provider、解析目标模型。
- `SettingsManager`：提供当前运行目录下的有效配置。
- `DefaultResourceLoader`：加载上下文文件、skills、prompts、themes 和 extensions。

资源加载完成后，extensions 可以注册额外 provider。随后模型运行时使用本地数据刷新一次模型目录。

## 5. 创建 AgentSession

`createAgentSessionFromServices()` 最终调用 `createAgentSession()`，把以下对象组合为一个会话：

```text
ModelRuntime + SettingsManager + ResourceLoader + SessionManager
+ model + thinking level + tools + extensions + history
```

`AgentSession` 负责模型请求、上下文构造、流式响应、工具调用、事件通知和会话写入。

`AgentSessionRuntime` 在外层持有当前 session，支持切换会话、切换目录和 reload 后重建运行环境。

## 6. 创建 InteractiveMode

`main()` 在交互模式下执行：

```ts
const interactiveMode = new InteractiveMode(runtime, options);
await interactiveMode.run();
```

`../packages/coding-agent/src/modes/interactive/interactive-mode.ts` 的构造函数创建聊天容器、输入框、状态区、widgets、footer、快捷键和主题控制器。

## 7. 初始化并启动 TUI

`InteractiveMode.run()` 首先调用 `init()`。主要顺序是：

1. 注册信号处理器。
2. 检查 `fd` 和 `rg`。
3. 创建聊天区 `ScrollView`。
4. 使用 `VStack` 组装页面。
5. 挂载组件并聚焦输入框。
6. 注册快捷键和输入提交处理器。
7. 调用 `ui.start()` 接管终端输入并首次渲染。
8. 应用主题。
9. 渲染版本、快捷键和引导文本。
10. 绑定 extensions 和 AgentSession 事件。
11. 显示已加载资源与历史消息。
12. 初始化 footer 和 provider 数量。

## 8. 等待第一句话

初始化完成后，`run()` 进入循环：

```ts
while (true) {
  const userInput = await this.getUserInput();
  await this.session.prompt(userInput);
}
```

用户按 Enter 后，`CustomEditor.onSubmit` 先判断 slash command、bash 命令和流式 steering。普通文本唤醒 `getUserInput()`，随后交给 `AgentSession.prompt()`。

## 职责汇总

| 部分 | 职责 |
| --- | --- |
| `cli.ts` | Node/tsx 进程入口 |
| `main.ts` | 参数解析、模式选择和启动编排 |
| `SettingsManager` | 配置读取与合并 |
| `SessionManager` | 会话历史与持久化 |
| `ResourceLoader` | 上下文、skills、prompts、themes、extensions |
| `ModelRuntime` | 模型目录、认证和 provider |
| `AgentSession` | 对话、模型请求、工具和事件 |
| `AgentSessionRuntime` | 当前 session 的生命周期与替换 |
| `InteractiveMode` | 交互页面及交互业务 |
| `pi-tui` | 终端输入、布局和 ANSI 渲染 |
| `CustomEditor` | 文本编辑和提交 |
