# 终端对话界面与 TUI

Pi 的交互页面不是网页，而是由仓库内的 `@earendil-works/pi-tui` 终端 UI 库实现。它读取终端键盘输入，并用 ANSI 转义序列局部重绘字符界面。

## 输入与渲染链路

```text
终端键盘输入
  → ProcessTerminal 读取 stdin
  → TUI 分发键盘事件
  → CustomEditor 更新输入状态
  → InteractiveMode 处理提交
  → 组件生成显示内容
  → TUI 通过 stdout 和 ANSI 序列重绘终端
```

## TUI 底层

- `../packages/tui/src/terminal.ts`：`ProcessTerminal`，管理 stdin/stdout 和终端 raw mode。
- `../packages/tui/src/tui.ts`：TUI 基础类、组件树、事件分发和渲染生命周期。
- `../packages/tui/src/tui-main-screen.ts`：普通终端屏幕渲染。
- `../packages/tui/src/tui-alt-screen.ts`：全屏 alternate screen 渲染。
- `../packages/tui/src/keybindings.ts`：TUI 层快捷键定义。

## Coding Agent 页面

页面的组合根位于：

```text
../packages/coding-agent/src/modes/interactive/interactive-mode.ts
```

页面结构：

```text
documentContainer
├── headerContainer
├── loadedResourcesContainer
└── chatContainer

bottom dock
├── pendingMessagesContainer
├── statusContainer
├── widgetContainerAbove
├── editorContainer
├── widgetContainerBelow
└── footerContainer
```

主要组件位于 `../packages/coding-agent/src/modes/interactive/components/`：

- `custom-editor.ts`：底部输入框。
- `user-message.ts`：用户消息。
- `assistant-message.ts`：模型回复。
- `tool-execution.ts`：工具调用。
- `status-indicator.ts`：运行状态。
- `footer.ts`：底部状态栏。

## 启动页内容

`interactive-mode.ts` 中的 `init()` 创建：

- `pi vX.Y.Z` 标题。
- 快捷键提示。
- `Press ctrl+o...` 引导。
- `Pi can explain...` 提示。
- 可通过 Ctrl+O 展开的 `ExpandableText`。

`showLoadedResources()` 渲染：

```text
[Context]
[Skills]
[Prompts]
[Extensions]
```

这些名称下的具体资源来自 `ResourceLoader`，不是硬编码的固定列表。
